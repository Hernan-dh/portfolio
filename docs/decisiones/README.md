# Decisiones

Este directorio contiene decisiones técnicas o funcionales duraderas. Los ADR se numeran y conservan aunque sean reemplazados.

Estados válidos: `propuesta`, `vigente`, `reemplazada` y `descartada`.

```bash
python scripts/documentar.py decision "Título de la decisión"
```

No crear ADR para cambios cosméticos, correcciones triviales o refactors sin cambio funcional.
