02

Applied AI · 2026

Deep Research

A research agent that plans multiple web searches and turns verified results into a detailed report.

A Pydantic-validated planner generates structured queries, which Python executes concurrently through Google Custom Search with a DDGS fallback. A separate writer synthesizes the evidence while deterministic post-processing appends five unique source links.

The agent workflow uses the OpenAI Agents SDK and the official OpenAI Python SDK, connecting Gemini and Groq through OpenAI-compatible endpoints without depending on OpenAI models.
